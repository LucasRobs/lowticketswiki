## 🚫 LISTA NEGRA (Padrões que falham sempre)

1. **Espionagem de terceiros** (Stalkeia, Spygram, etc.) → Fraude, ilegal, chargeback 30%+
2. **Revenda de conta compartilhada** (ChatGPT, Netflix, etc.) → TOS violation, instável
3. **Front isca + upsell obrigatório oculto** → Reclamações, chargeback, ban de gateway
4. **Acesso vitalício a serviço alheio** → Fornecedor some, suporte zero, risco legal
5. **Serviços personalizados via gateway** (consultoria, mentoria 1:1) → Não escala
6. **Produtor "desconhecido" + porta única** → Sem histórico, some em semanas

## 🛠 STACK SUGERIDA PARA MVP RÁPIDO

**Funil A (Prompts IA)** - 3 dias
- Landing: Carrd / Framer / HTML puro
- Checkout: PerfectPay / Cakto / Stripe
- Entrega: Notion (público) + Email automático (MailerLite/Brevo)
- Tráfego: Meta Ads (Interesses: Freelance, Marketing Digital, Produtividade)

**Funil B (Micro-SaaS)** - 10 dias
- App: Next.js + Supabase (auth, db, storage)
- IA: OpenAI API / Anthropic API
- Pagamento: Stripe (subscription + lifetime) + PerfectPay/Cakto via webhook
- Deploy: Vercel (gratuito para começar)

**Funil C (Auditoria)** - 5 dias
- Script: Python (haveibeenpwned API + hunter.io + clearbit)
- Frontend: Streamlit / Gradio / Next.js
- Relatório: Jinja2 → PDF (weasyprint)
- Recorrência: Stripe Billing + webhook para re-rodar script
